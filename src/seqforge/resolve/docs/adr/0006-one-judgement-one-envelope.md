# 6. One judgement, one envelope — `chemistry` is the library section's only `Evidenced` field

`chemistry`, `assay`, `read_layout` and `files[].read_id` all read as interpretive, and wrapping
each in its own `Evidenced` printed one confidence four times in the pilot's manifest, because it
was always one decision. Envelopes track decisions, not fields: `chemistry` carries the joint call
over *(which technology, which file is which read)* and the other three follow from it. Four
envelopes filled from one variable cannot disagree, so they were never four truths and R4's
`Conflict` machinery had nothing to detect between them — before adding an `Evidenced`, ask whether
it could ever disagree with an existing one.
