# 21. One deposit is one source, at every layer — the slot the submitter typed outranks a reading of it

An archive re-renders the submitter's typed columns into its free text, so a model quoting that text
arrives with a real, entailed claim competing with the column it came from — and the equal-authority
rule stored null, destroying a fact the archive had supplied. Within one source a typed value now
outranks a reading of that source's prose, and a harvested span byte-equal to a typed column of the
record that produced the document is not prose at all. Every alternative compares the two strings —
containment, overlap, synonym tables, punctuation folding — which closes the paraphrase case and
leaves the misfiling open, where a model files a genotype under `treatment` and the strings share
nothing; a rule keyed on one archive's title grammar lost because most datasets never had an
accession.
