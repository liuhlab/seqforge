# 36. A verb that needs a file list is handed the table that states it

A cell topped up across two runs — 20 of 190 well-labelled plate deposits — rendered two paths after
a one-value `--r1`, and the wiring gate structurally cannot see it: `snakemake -n -p` formats
`shell:` blocks and never runs them, so every arity, quoting and ordering fact in a rendered command
line is unguarded. Handing the verb `--units` and `--sample` takes the file list off the command
line altogether; a comma-joined list would import STAR's and chromap's argument grammar into a verb
we define ourselves, and a repeated `--r1` would leave the pairing inferred from two independently
sorted lists, where equal record counts across two runs pair one run's barcodes against another's
cDNA at exit 0. Refusing a plural deposit at compose time declines something merely ordinary, and
concatenating each role upstream stages the whole plate on disk for work the extractor does for free
by reading two files in sequence.
