# 20. A family term narrows; it does not conflict — and specificity, not verbosity, ranks the match

**Status.** Absorbs ADR-0028 — specificity, not verbosity, ranks a chemistry match.

A curated form must be carried by the value, never the reverse — the reverse read `RNA-Seq` and
`Illumina` as chemistry claims — and requiring an exact alias instead was rejected because it
refuses every realistic prose spelling. An asserted node that is an ancestor of the observed leaf is
agreement, not a weak conflict: a `Conflict` whose positions do not disagree teaches a reader that
the file is full of them. Rank among carried forms is specificity, declared or entailed, never
counted — token count measures verbosity and inverts across nodes, so a phrase that only describes a
run outranked a chemistry's own name — and every component reads only the two strings, since a rank
taken off the KB's own statistics would let an unrelated new spec re-point an existing `run_id`.
