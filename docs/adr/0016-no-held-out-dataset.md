# 16. No held-out dataset and no withheld benchmark case — a pre-registered prediction instead

A set you may not look at cannot also be the worked example, the tutorial source and the fixture
that prices a defect, so the guard reserving `PRJNA1027859` was deleted rather than suspended; the
real work was done by `expected.yaml`, written from declared metadata before any run, because only a
prediction can be wrong. One level out, the same argument publishes a benchmark case a real dataset
makes red — a corpus holding only the cases it passes measures nothing — so a package stays off the
public repo only for copyright or an ungraded test set, and one the corpus does not hold reports
**absent** under its own name rather than as a skip that reads as a bad network day.

**Status.** Supersedes the held-out designation. Absorbs ADR-0018 — a red case is published anyway.
