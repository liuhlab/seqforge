# 57. A model writes an answer only where code can check it, and code decides whether it stands

The old rule was "the LLM has exactly two jobs", and it was true of the compiler but false of the
study chain, where models draw a study's bounds and write its reading. The rule is now stated by what
code can check: a model writes only answers that code can verify, and code owns the formats, greps
every quote back, holds the threshold that settles an answer and derives the relations. A model never
writes code, never sets a threshold and never reads a chemistry from bytes. Two alternatives lost:
keeping "two jobs" for the compiler with a separate rule for studies, which leaves two rules to drift
apart, and a numbered list of jobs, which is wrong the day a stage adds one.
