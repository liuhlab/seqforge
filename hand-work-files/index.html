    Files from the hand work¶

    This page lists every file that the hand work on the standard set produced. It is written for someone outside the project who builds an evaluation on these files. For each kind of file it gives the path, the count, the format, who or which model made the file and how, and a few lines of Python that load it.

    This page uses five words:

    • A study is one piece of research: the experiments one paper reports, or one project that has no paper yet.
    • A Series is one deposit in GEO, the Gene Expression Omnibus, a public archive of sequencing data. A Series has an id such as GSE241718. One study can span several Series.
    • A study's bounds say which Series and which papers belong to the study.
    • The standard set is a fixed list of 50 small GEO studies.
    • A study's reading says what each sequenced sample is and which labels the study varied.

    Hand work means work done one study at a time, outside the unattended chain that the study workflow describes. The name does not mean that a person did it. A model made every file on this page, or code wrote the file from a model's answer. No person has checked any of them.

    Every file in one table¶

    All files are under evals/standard-set/ in the seqforge repository. <ID> is the Series that a study was picked by, and it is also the name of the study's folder. The counts were measured on 2026-11-19.

    File Path Count Made by Format
    The pick pick.yaml 1 A model session, 2026-11-19 On this page
    The study file <ID>/study.yaml 50 The judge command On this page
    The bounds <ID>/bounds.yaml 50 Code, from the two models' answers The bounds file
    The draft <ID>/draft.yaml 50 deepseek/deepseek-v4-flash On this page
    The verdict <ID>/verdict.yaml 50 claude-fable-5-2 On this page
    The reading <ID>/reading.yaml 5 claude-fable-5-2 The reading file
    The reading's verdict <ID>/reading.verdict.yaml 5 claude-fable-5-2, in a second pass On this page
    The reading's notes <ID>/reading.notes.md 5 The model that wrote the reading Markdown text
    A person's answers none yet 0 Nobody yet The rule

    That is 216 files: the pick, four files for each of the 50 studies, and three more for each of the five studies that have a reading. The folder also holds a README.md, which describes the commands.

    This snippet counts the files again. Run it, and every other snippet on this page, from the root of the repository. Each snippet needs Python 3 and PyYAML and nothing else.

    import collections
import pathlib

root = pathlib.Path("evals/standard-set")
print(len([p for p in root.iterdir() if p.is_dir()]))  # 50
print(sorted(collections.Counter(p.name for p in root.glob("*/*")).items()))

    The files hold identifiers and the models' own words. The only text of a record or of a paper in them is short quotes, most of them under passages in a reading. The records are public at GEO, and PubMed lists each paper by its number.

    The standard set¶

    The 50 studies were picked on 2026-11-19. A small model then drafted each study's bounds, and a large model judged each draft once. Three commands did that work for each study, in this order:

    seqforge pass start standard-set-bounds --ceiling-usd 0.5 --keys KEYS.txt
seqforge standard-set draft
seqforge standard-set judge <ID>

    The first command asks the small model about each study on a list. The second command writes draft.yaml from the answers. The third command asks the large model about one study and writes verdict.yaml, bounds.yaml and study.yaml. The standard set's own page describes each command. The commands read GEO records and papers from liulab-data, the lab's package that stores them. You can load every file without that store, but you cannot run the commands again without it.

    The judge agreed with 48 drafts and replaced 2, those of GSE101112 and GSE126954. It was unsure about none.

    pick.yaml: the 50 picked, the spares and the replaced¶

    Path: evals/standard-set/pick.yaml. One file.

    Made by: a model session on 2026-11-19. The file names no model. Its header says that the picker judged each study's direction, shape and design from the Series' public GEO record and the PubMed abstract of its paper. The picker read 302 Series records and 263 abstracts, a count taken from the note on record links.

    The file has six top-level fields:

    Field Holds
    store_build The build of liulab-data's store that the counts and the links were read from: 20261107T163933Z.
    picked_on The date of the pick: 2026-11-19.
    limits The size limits a study had to fit: the most samples, experiments and linked Series. The hard_shape_ limits are wider and apply to a study picked for a hard shape.
    studies The 50 picked studies: 17 on aging, 17 on neurodegeneration and 16 on C. elegans.
    spares 14 studies held back to take the place of a picked study that fails.
    replaced The studies taken out after the pick, each with the spare that took its place and the reason it failed. The list is empty: no study has been replaced.

    Each entry of studies and of spares has these fields:

    Field Holds
    id The Series the study was picked by.
    direction aging, neurodegeneration or c_elegans. A study counts under one.
    also_fits The other directions the study could count under. May be empty.
    hard_shape The hard case the study was picked for: recites_older_series, paper_over_several_series, superseries, series_with_two_studies or series_without_paper. null for a plain study. 34 of the 50 are null.
    linked_series Every Series linked to the picked one, the picked one included.
    pmids Every paper linked to any of those Series, each a PubMed number written as text.
    assay The kind of sequencing, in the picker's short words.
    compiles_today The library chemistry that the record's protocol text points to, by the name seqforge gives it. A list when the study has two, and null when seqforge supports none. No sequencing read was looked at.
    compiles_fully true when every library of the study is in a chemistry that compiles_today names.
    known_dataset true for a study that seqforge had already worked on before the pick. 5 of the 50.
    n_samples, n_experiments The GEO samples and the SRA experiments of all the linked Series together.
    design The design, in the picker's short words.
    reason_picked One or two sentences.
    status settled, shape_to_confirm or shape_not_found. The last one marks a study picked as possibly two studies in one Series that turned out to be one study. 3 of the 50.
    spare_for Spares only. The direction or the hard shape that the spare stands in for. 
    import yaml

with open("evals/standard-set/pick.yaml", encoding="utf-8") as handle:
    pick = yaml.safe_load(handle)
print(len(pick["studies"]), len(pick["spares"]), len(pick["replaced"]))  # 50 14 0
print(pick["studies"][0]["id"], pick["studies"][0]["reason_picked"])

    study.yaml: the facts about one pick¶

    Path: evals/standard-set/<ID>/study.yaml. 50 files.

    Made by: the seqforge standard-set judge command, when it wrote the verdict. It copies the pick's facts, takes summary from the draft, and adds three fields from the verdict. Each file was rewritten once, on 2026-11-20 (UTC), to move the bounds out into bounds.yaml.

    Field Holds
    id The folder name: the Series the study was picked by.
    summary One short line that says what the study is. From the draft.
    direction, also_fits, hard_shape, reason_picked As in pick.yaml.
    store_build The store build the identifiers were read from. All 50 files say 20261107T163933Z-subset. The subset is a small copy of the build that pick.yaml names, cut down to the records of these studies.
    records Every linked record, by identifier only: series, superseries (which of those Series is a SuperSeries, or null), bioprojects and pmids.
    bounds_from draft when the judge agreed with the draft (48 files), judge when the judge's bounds replaced it (2 files).
    status settled, or unsure when the judge was unsure. All 50 say settled.
    read_to_decide What the judge had to read: records, abstract, full_paper. 
    import yaml

with open("evals/standard-set/GSE241718/study.yaml", encoding="utf-8") as handle:
    study = yaml.safe_load(handle)
print(study["id"], study["direction"], study["records"]["series"], study["bounds_from"])

    bounds.yaml: the study's bounds¶

    Path: evals/standard-set/<ID>/bounds.yaml. 50 files.

    Format: The bounds file describes every field. All 50 files say format: 1.

    Made by: code, which converted the bounds that the two models drew. models.bounds names the model whose bounds became the study's: deepseek/deepseek-v4-flash in 48 files and claude-fable-5-2 in 2. The files hold no date. Git history dates the conversion to 2026-11-20 (UTC).

    The 50 files hold 74 claims: 57 Series kept and 17 records left out, in 10 studies. Seven studies have two Series. Four studies have no paper. In three studies the folder's Series is a SuperSeries, so it is in left_out and not in series: GSE117724, GSE140511 and GSE240375.

    import pathlib

import yaml

for path in sorted(pathlib.Path("evals/standard-set").glob("*/bounds.yaml")):
    bounds = yaml.safe_load(path.read_text(encoding="utf-8"))
    kept = [claim["id"] for claim in bounds["series"]]
    left_out = [claim["id"] for claim in bounds["left_out"]]
    print(bounds["study"], kept, bounds["papers"], left_out)

    draft.yaml: what the small model answered¶

    Path: evals/standard-set/<ID>/draft.yaml. 50 files.

    Made by: deepseek/deepseek-v4-flash, through the drafting pass and the draft command. The model read the records of the linked Series and the abstract of each paper, and nothing else. The drafts are dated from 2026-11-19 23:38 to 2026-11-20 00:05 (UTC).

    Field Holds
    id The study.
    model The model that answered.
    pass The pass that asked: its kind, its version and its number, such as standard-set-bounds/2026.11.3/pass-5. The 50 drafts come from four passes.
    when The time of the answer, as text: 2026-11-20T00:02:16Z.
    summary One line that says what the study is.
    bounds The model's answer. See below.
    checks_failed What the code found malformed in the answer. Empty in 49 drafts. The draft of GSE126954 put a sample id among the left-out records.

    bounds in a draft is the model's answer. It is not in the bounds format:

    Field Holds
    series The Series the model kept.
    papers The papers the model kept, each written pmid:<number>.
    reason One line.
    left_out A mapping from each record left out to the reason. In bounds.yaml the same thing is a list of claims.
    split_samples An older field. See What this page promises. 
    import yaml

with open("evals/standard-set/GSE241718/draft.yaml", encoding="utf-8") as handle:
    draft = yaml.safe_load(handle)
print(draft["model"], draft["pass"], draft["when"])
print(draft["bounds"]["series"], draft["bounds"]["papers"], draft["bounds"]["left_out"])

    verdict.yaml: what the judge answered¶

    Path: evals/standard-set/<ID>/verdict.yaml. 50 files.

    Made by: claude-fable-5-2, through the judge command, once for each study. The judge got the draft and what the drafting model saw, and it could open the full records and the full text of the papers. The verdicts are dated from 2026-11-19 23:38 to 2026-11-20 00:10 (UTC).

    Field Holds
    id The study.
    model The model that judged.
    when The time of the verdict, as text.
    agrees true when the judge agrees with the draft's bounds. 48 are true and 2 are false.
    bounds null when the judge agrees. Otherwise the judge's own bounds, with the same five fields as the bounds in a draft.
    reason Why the judge agrees or disagrees.
    unsure true when the judge could not decide. All 50 are false.
    read What the judge read: records, abstract, full_paper. The judge opened a full paper for 7 studies.

    The bounds that the two models settled on are the draft's when the judge agrees, and the judge's when it does not:

    import pathlib

import yaml

for folder in sorted(pathlib.Path("evals/standard-set").glob("GSE*")):
    draft = yaml.safe_load((folder / "draft.yaml").read_text(encoding="utf-8"))
    verdict = yaml.safe_load((folder / "verdict.yaml").read_text(encoding="utf-8"))
    answer = draft["bounds"] if verdict["agrees"] else verdict["bounds"]
    print(verdict["id"], verdict["agrees"], answer["series"], sorted(answer["left_out"]))

    The five worked readings¶

    Five of the 50 studies have a reading, one for each kind of design. A model wrote each reading. A second model pass checked each reading against the records and the paper. No person has checked any of them. Where the second pass disagrees with a reading, the reading is left as written, and the disagreement is in the verdict.

    Study Kind of design Samples Passages Second pass agrees Disagreements
    GSE100021 Two groups: a treatment against a control 8 29 No 1
    GSE112068 A dose series and a time series 23 45 No 3
    GSE235532 Pull-down libraries with their input controls 24 30 Yes 1
    GSE117724 Two assays: 18 RNA-Seq libraries and 2 ChIP-Seq libraries 20 54 Yes 0
    GSE241718 One paper over two Series 8 28 Yes 2

    No command made these files. The process was:

    1. A large model read the records of the study's Series and its paper, and wrote reading.yaml and reading.notes.md. For four studies it read the records, the abstract and the full text. GSE112068 has no paper, so the model read the records only.
    2. A second pass read the same sources again and checked the reading. It looked for every quote in the field or the paper section that the reading names, and it compared the samples with the study's bounds. It wrote reading.verdict.yaml.
    3. The second pass changed a reading only to make it pass the format check. Each such change is listed under format_fixes in the verdict: 7 changes over the five readings.

    Each file records the model as claude-fable-5-2, for the reading, for its probabilities and for the second pass.

    reading.yaml: the study reading¶

    Path: evals/standard-set/<ID>/reading.yaml. 5 files.

    Format: The reading file describes every field. All five files say format: 1.

    Made by: claude-fable-5-2, named in models.reading and in models.probabilities. The files hold no date. They were added to the repository on 2026-11-20 (UTC).

    A sample has every claim under shared, except a label that its own row writes. The snippet applies that rule:

    import yaml

with open("evals/standard-set/GSE241718/reading.yaml", encoding="utf-8") as handle:
    reading = yaml.safe_load(handle)
for sample, row in reading["samples"].items():
    claims = {**reading["shared"], **row}  # a row's claim replaces the shared claim whole
    print(sample, claims["tissue"]["text"], claims["age"]["level"], claims["assay"]["p"])
print(reading["passages"][14]["quote"])  # a passage number loads as a whole number

    The relations between the samples are not stored. seqforge study relations <file> derives them, and the reading file describes its output.

    reading.verdict.yaml: what the second pass found¶

    Path: evals/standard-set/<ID>/reading.verdict.yaml. 5 files.

    Made by: claude-fable-5-2, in a second pass. The verdicts are dated from 2026-11-20 01:39 to 02:05 (UTC).

    Field Holds
    id The study.
    model The model of the second pass.
    when The time of the verdict. Four files write it as text. GSE100021/reading.verdict.yaml writes it without quotes, so PyYAML returns a datetime for that one file.
    read What the second pass read: records, abstract, full_text.
    format_fixes A list of text. Each item is one change that the second pass made to reading.yaml so that the file passes the format check.
    quotes Three counts of the quotes in the reading: checked, found, and not_found, a list. In all five, every quote was found: 186 quotes together.
    samples_match_bounds true when the samples of the reading are exactly the samples of the Series in the study's bounds. true in all five.
    agrees The second pass's overall judgement of the reading. true in 3 and false in 2. A verdict can agree and still list disagreements.
    disagreements A list, one item for each point where the second pass would write the reading differently. May be empty.
    unsure A list of text: what the second pass could not settle from the sources. Each verdict has 3 to 6.
    reason The second pass's account of what it checked and found.

    Each item of disagreements has five fields:

    Field Holds
    where The place in reading.yaml, such as shared.dose or samples.GSM7720368.donor. One item can name several places.
    says What the reading says there.
    should_be What the second pass would write.
    why The reason.
    passages The passages that the point rests on, by number. One item in the verdict of GSE241718 also quotes a record line as text. 
    import pathlib

import yaml

for path in sorted(pathlib.Path("evals/standard-set").glob("*/reading.verdict.yaml")):
    verdict = yaml.safe_load(path.read_text(encoding="utf-8"))
    print(verdict["id"], verdict["agrees"], verdict["quotes"]["found"], len(verdict["unsure"]))
    for item in verdict["disagreements"]:
        print("  ", item["where"], "->", item["should_be"])

    reading.notes.md: what the format could not hold¶

    Path: evals/standard-set/<ID>/reading.notes.md. 5 files.

    Made by: the model that wrote the reading, at the same time. Each file is free Markdown text with no fixed fields. It says what the model read and what the reading format could not hold for this study, or held badly.

    import pathlib

for path in sorted(pathlib.Path("evals/standard-set").glob("*/reading.notes.md")):
    notes = path.read_text(encoding="utf-8")
    print(path.parent.name, notes.splitlines()[0])

    Answers a person gave while checking¶

    There are none yet. No person has answered a question about any of the 50 studies, and no person has corrected a file. Every study folder holds only the files in the table at the top.

    The rule for the first one is fixed. An answer that a person gives while checking is saved as a small plain file. The file holds the question, the study, the answer, who gave it and when. No folder and no command exist for such files yet. When the first answer is saved, this page lists its path.

    What this page promises¶

    Every file listed here is at the listed path, in the current format. There is one format at a time. A change to a format rewrites every existing file in the same change, and this page changes with it. The page does not promise that the content of a file stays the same.

    Two kinds of file have a written format and a check:

    seqforge study check-bounds evals/standard-set/<ID>/bounds.yaml
seqforge study check-reading evals/standard-set/<ID>/reading.yaml

    All 50 bounds files and all five readings pass their check (measured on 2026-11-19).

    The other files have no format number, and their fields are the ones this page lists. The drafts and the verdicts are kept as the models wrote them, so they hold fields from before the bounds format:

    • split_samples is in the bounds of all 50 drafts, and in the bounds of the 2 verdicts that have bounds of their own. It comes from when one Series could be split between two studies. A study is now whole Series, and the bounds format rejects the field. It is empty in all 50 drafts and in the verdict of GSE101112. In the verdict of GSE126954 it lists seven sample ids.
    • left_out in a draft or a verdict is a mapping from a record to a reason. In bounds.yaml it is a list of claims.
    • A paper is written pmid:<number> in the bounds, the drafts, the verdicts and the readings. In pick.yaml and in study.yaml it is the bare number, as text.
    • A full paper is full_paper in study.yaml and verdict.yaml, and full_text in the two reading files.

    Known wrong or stale facts in the files¶

    Do not build on these lines without reading this list.

    1. GSE241718/study.yaml describes the two Series wrongly. Its reason_picked says that one Series holds whole cells and one holds nuclei. The protocol on every sample record, the summary of both Series and the paper say that all eight libraries are single-nucleus. The paper says that the data were uploaded in two stages. The entry in pick.yaml has the same sentence, and its assay and design say the same. That entry also names the chemistry as 10x-3p-gex, while the protocol on every sample record names a Singleron kit.
    2. GSE126954/bounds.yaml still speaks of seven samples. Its claim and its reason say that "the seven embryo samples are its own data". The judge had drawn the study as seven of the eight samples. A study is whole Series, so the bounds are now the whole Series of eight. The eighth sample is a re-deposited sample of an older study. Telling it apart is left to the study's reading, and this study has none yet.
    3. The bounds carry no probability and no quote. All 74 claims in the 50 bounds files are marked inferred, with the model's reason as the text. Every p is null, models.probabilities is null, and passages is empty. null means that no model has given a probability, not that the claim is in doubt.
    4. One when is later than its file. GSE100021/reading.verdict.yaml says 2026-11-20T02:05:00Z. The commit that added the file is dated 23 minutes earlier. The model wrote the time itself.
    5. The readings keep what the second pass disagrees with. The table below has one line for each reading.
    Reading What the second pass disagrees with
    GSE100021 shared.dose writes the value 1.7e+12 with the unit viral_particles_per_side. The source sentence gives the content of the suspension, not the amount each side received.
    GSE112068 shared.sex is na and should be unknown, on all 23 samples. The three untreated samples have control as their treatment, where na fits. The time factor cites passages that do not list its levels.
    GSE117724 Nothing. The second pass lists four points it could not settle, such as the stage of the worms at harvest.
    GSE235532 The reading leaves out the time of collection, and its notes say wrongly that the format has no place for it.
    GSE241718 The donor ids of the four young libraries are a guess, and their p of 0.5 is too high. Passage 19 names two sample records, and all eight hold the quote.

    The second pass also could not settle the age of the four aged libraries of GSE241718. The sample records say 24 months, and the Series designs and the paper say 26. The reading writes 26 with a p of 0.55.
